# 学习日志时间轴

一个无需构建、默认无需联网的纯前端学习计划工具。页面使用双栏时间轴展示每日计划与实际记录，并整合复习安排、专注计时、月历、统计和分级学科管理。

## 主要功能

### 时间轴

- 点击“在时间轴选时间”后，直接在任意半区选择开始和结束时间。
- 首次点击哪个区域，就自动使用哪个区域，无需预先切换计划区或记录区。
- 默认选区、选点间隔、小时高度、隐藏时段和计划/记录比例均可设置。
- 支持同时隐藏多个时段，例如 `0-7,23-24`。
- 默认显示可调大小和透明度的 10 分钟点；事件轴可放在区域中间或下方。
- 可直接拖动中央小时线调整双栏比例，也可通过“编辑布局”调整时间轴/右栏宽度和专注/复习高度。
- 双击事件可编辑，右键可编辑或删除。

默认快捷键 `Ctrl + Enter` 可快速进入或退出选点模式，快捷键可在设置中修改。

### 复习任务

- 支持常用间隔、艾宾浩斯间隔和自定义复习天数。
- 推迟某次复习时，该事件后续复习会按相同天数顺延。
- 可以只放弃某一次复习，不影响后续复习日期。
- 支持今天、本周、本月和全部任务筛选。

### 月度视图

点击右侧日期可打开月历。每天会显示：

- 记录区事件内容；
- 当天记录总时长；
- 待复习任务数量。

点击月历中的日期即可跳转到当天时间轴。

### 专注计时与沉浸界面

- 支持正计时和倒计时。
- 内置 15、25、45、50、60 分钟，并支持自定义分钟数。
- 开始计时后自动进入沉浸界面，也可退出沉浸界面后继续后台计时。
- 沉浸界面支持倒数日、励志句子、背景透明度，以及纯白、自然、动漫柔光、星空、天空和暖色主题。
- 结束后填写学习详情，记录会自动加入时间轴记录区。

项目保持离线优先，因此主题背景和励志句子使用本地样式与本地内容，不会自动请求网络图片。

### 统计

- 累计专注次数、总时长和日均时长；
- 今日专注次数和时长；
- 按本日、本周、本月或本年查看学科时长分布；
- 本月每日专注折线图；
- 本年每月专注折线图；
- 支持一级、二级和三级学科筛选；
- 每块统计卡片可以单独隐藏或显示。

### 学科管理

- 独立的学科管理模块，可添加或删除一级学科。
- 每个学科可以设置颜色、文字大小、透明度、加粗、斜体和默认复习规则。
- 支持添加二级和三级科目，并可分别决定是否生成复习任务。
- 时间轴事件弹窗使用三级联动选项，每一级都可以停止继续选择。
- 学科详情包括本月专注日历、当前/最高连续打卡、累计专注、年度热力图和历史记录。

### 页面与数据

- 顶栏采用紧凑设计，设置、导入导出和撤销重做收纳在右上角“•••”菜单。
- “清空全部事件”仅位于设置的二级页面，降低误触风险。
- 页面本身固定不滚动，时间轴和复习任务列表各自独立滚动。
- 数据保存在浏览器 `localStorage`，支持 JSON 导入导出、撤销和重做。
- PNG 时间轴使用纯白背景，不包含交互光标。

## 使用方法

直接用浏览器打开 `index.html`，无需安装依赖。

1. 点击“在时间轴选时间”，或按 `Ctrl + Enter`。
2. 在计划区或记录区点击开始时间，再点击结束时间。
3. 选择一级、二级或三级学科，填写内容并保存。
4. 点击右侧学科按钮开始专注；结束后填写详情，记录会自动进入时间轴。
5. 点击日期查看月历，点击“统计”或“学科管理”进入对应模块。

按 `Esc` 可以退出选点、关闭弹窗或退出沉浸界面；`Ctrl + Z` 和 `Ctrl + Y` 分别用于撤销和重做。

## 项目文件

```text
index.html   页面结构与各功能模块
styles.css  页面样式、响应式布局、图表和沉浸主题
app.js      时间轴、复习、统计、学科、计时和数据逻辑
```

清理浏览器数据前，建议先通过右上角菜单导出 JSON 备份。
