# 学习日志时间轴

一个无需构建、默认无需联网的纯前端学习计划工具。页面使用双栏时间轴展示每日计划与实际记录，并把结构化学习记录、复习安排、专注计时、月历、统计和分级学科管理串成一条完整流程。

## 2026-09-01 清单收尾 · v31

- 学习动作改为“新知 / 运用 / 记诵”三选一并配套线性图标，默认新知；旧视频、习题、背诵数据自动映射。
- 日报与统计都可在弹窗内用左右箭头切换日期或统计周期；月/年趋势默认完整展示，无需横向拖动。

## 主要功能

### 时间轴

- 点击“在时间轴选时间”后，直接在任意半区选择开始和结束时间。
- 首次点击哪个区域，就自动使用哪个区域，无需预先切换计划区或记录区。
- 默认选区、选点间隔、小时高度、隐藏时段和计划/记录比例均可设置。
- 支持同时隐藏多个时段，例如 `0-7,23-24`。
- 时间轴使用纯白背景和简洁的分钟点，不再绘制横向小时线；小时数字加大，长时间浏览时更容易定位。
- 分钟点大小和透明度可调，分享图也会保留分钟点；事件轴可放在区域中间或下方，箭头粗细和箭头尖大小可调。
- 学习记录使用实线箭头，复习记录的粗细、箭头尖和虚线样式可独立配置；标签用颜色表示一级学科，并按“二级学科 + 学习动作图标 + 事件名称 + 资料定位”左对齐排版。
- 可直接拖动中央小时线调整双栏比例，也可通过“编辑布局”调整时间轴/右栏宽度、专注/复习高度。
- 跨小时事件优先在箭头空余最多的小时行显示文字，文字左端对齐箭头左端，资料定位紧跟名称；所有标签固定单行，空间不足时省略并通过悬浮提示显示完整内容，每小时行高始终采用当前布局设置。
- 单击事件打开学习详情，双击编辑；右键菜单支持查看详情、编辑、删除以及快速开始计划。
- 历史记录编辑保留原日期；时间表单支持时、分、秒及毫秒，结束可设为 `24:00:00`。仅修改名称、笔记等内容不会舍入原始计时时段。
- 设置中可切换 `7–22` 紧凑视图并恢复开启前的时间轴设置，也可把顶栏切换为仅图标模式；按钮悬停会显示功能说明。

默认快捷键 `Ctrl + Enter` 可快速进入或退出选点模式，快捷键可在设置中修改。

### 计划驱动学习

- 计划区事件到达开始时间后，网页会弹出专用提醒窗口，展示学科、事件名称、学习动作、计划时段和资料定位。
- 提醒窗口支持“一键开始学习”“10 分钟后提醒”和“忽略本次”。
- 一键开始会自动带入计划事件的信息，启动正计时并进入沉浸界面；计时页面会持续展示当前计划内容。
- 也可以右键计划区事件，随时选择“开始学习”，无需等待提醒。
- 完成后填写实际学习范围、结果和掌握程度，记录会写入记录区，并按学科规则生成复习任务；原计划会显示完成标记。

提醒支持可调音量、时长和类型的提示音，也可授权浏览器发送 Windows 系统通知。页面保持打开时会准时检查；浏览器暂停后台页面后，重新进入页面会立即补查当前仍在进行的计划。

### 结构化学习记录

新增事件卡片按功能分为可折叠区，并通过一个可筛选的学科路径输入框选择一级、二级或三级学科。统一使用事件名称标识任务，不再提供独立知识点字段；此外还可以保存：

- 事件类型：学习、复习或自定义；
- 学习动作：新知、运用、记诵，单选；
- 事件名称、资料定位和独立学习进度“学到哪”；
- 掌握程度：尚未判断、薄弱、部分掌握、已掌握；
- 学习摘要、学习笔记、遗留内容和重点标记。

这些信息会同时用于时间轴标签和后续复习卡片，避免复习任务只剩下一段难以辨认的备注。

单击时间轴箭头或文字可查看完整事件名称、资料定位、累计时长、各段记录、笔记和遗留内容，复习排期位于详情底部。双击可编辑事件设置。笔记不会显示在时间轴上。

### 历史数据兼容

闪卡功能已下线，全部入口、页面和计算逻辑已移除。已有事件中的旧闪卡数据和旧知识点字段原样保留在本地数据及 JSON 备份中，不执行转换或删除。旧事件缺少事件名称时，显示名称兼容读取旧知识点字段。

### 遗留待清池

- 所有事件的遗留习题和问题会统一汇总到“待清池”，但数据仍挂载在原事件上。
- 可从待清池直接开始计时处理；保存结果后会自动标记完成。
- 也可手动完成或恢复，状态会同步到事件详情与关联复习卡片，同时保留原始遗留文字作为学习痕迹。
- 同一任务的分段及继承自同一来源的相同遗留事项只显示一条，完成/恢复同步关联记录；无来源关系的相同文字不会合并。

### 复习任务

- 支持常用间隔、艾宾浩斯间隔和自定义复习天数。
- 手动保存的已完成学习记录或计时任务最终完成后，生成每日复习清单，并按一级学科分组。暂停中的学习任务不生成复习。
- 清单将加粗的事件名称与正常字重的资料定位放在一起，保留学习动作、掌握程度、日期、次数和重点，不再输出建议、遗留内容或摘要。
- 清单提供“当日、本周、全部”筛选和独立全屏查看；跨日顺延或手动推迟某一轮时，后续未完成轮次会按相同天数联动顺延。
- 页面恢复、点击“今”及持续前台运行跨日时会补查顺延，不需要整页刷新；重复检查不会重复推迟。
- 复习间隔按真实天数显示，例如 D1、D3、D7、D14，而不是按第几次复习误写成 D2、D3。
- 掌握程度使用灰色（尚未判断）、红色（薄弱）、黄色（部分掌握）、绿色（已掌握）背景。
- 点击事件名称或“查看详情”可打开详情卡，展示基础信息、原学习信息和完整复习历程。
- 在详情卡开始前可确认或修改复习起点；点击“开始复习”进入统一的事件录入与计时界面。暂停后可从清单或未完成列表继续。
- 复习每次暂停立即生成该段虚线记录，但不改变本次复习的待完成状态；只有选择“完成”后，才结算累计时长、范围和掌握程度。
- 新掌握程度会同步到原学习事件和后续复习任务，形成可持续更新的复习状态。
- 推迟某次复习时，该事件后续复习会按相同天数顺延。
- 可以只放弃某一次复习，不影响后续复习日期。

### 月度视图

点击顶部当前日期可打开月历；日期旁的“← / 今 / →”用于前一天、回到今天和后一天。每天会显示：

- 记录区每个事件的内容和独立时长；
- 当天记录总时长；
- 待复习任务数量。

点击月历中的日期即可跳转到当天时间轴。

### 专注计时与沉浸界面

- 支持正计时和倒计时。
- 计时前可选择“学习任务”或“复习任务”。
- 内置 15、25、45、50、60 分钟，并支持自定义分钟数。
- 开始计时后自动进入沉浸界面，也可退出沉浸界面后继续后台计时；活动计时会保存到本地，页面重新激活或重新打开时按真实时间恢复并补查是否到期。
- 沉浸界面支持倒数日、励志句子、背景透明度，以及纯白、自然、动漫柔光、星空、天空和暖色主题；也可使用网络图片地址或不超过 4MB 的本地图片。
- 倒数日字号与位置可以调整。
- 普通计时区和沉浸界面保持笔记同步；沉浸卡片可按 Tab 依次填写资料定位、事件名称、摘要、笔记、遗留内容、学习动作和掌握程度，结束时自动带入学习记录。
- 沉浸输入采用 16px 深色文字，计时数字缩小，底部提供常驻暂停和完成入口；顶部“返回”只退出沉浸，计时继续。
- 支持 Document Picture-in-Picture 的浏览器会显示“悬浮小窗”按钮，可在置顶小窗中暂停、结束或返回沉浸界面；不支持时自动隐藏。
- 学习和复习均支持暂停、继续、完成和放弃；暂停立即保存本段时间，未完成列表可跨日接续。
- 结束面板可选择“完成”或“未完，后续继续学习”，遗留内容用于记录待完成部分；学习摘要默认留空。
- 多段学习共享同一任务，累计时长仅包含实际计时，暂停间隔不计入。跨午夜时段自动按日期拆分。
- 编辑同一任务的名称、学科和学习内容会同步至其他分段，时间只修改当前片段并重算累计时长。正在计时的任务及其关联来源需要先暂停再编辑或删除。
- 来源记录更新时，暂停中的复习同步名称和学科，同时保留自己的进度、摘要和笔记；来源删除或不再生成复习时，相关未完成状态会一起清理，已保存的复习片段仍保留。
- 学习任务仅在最终完成时生成一组复习安排，以完成日期作为间隔起点；复习任务仅在完成时标记该次复习完成。
- 放弃只结束未完成状态，已保存的各段记录仍保留。复习任务放弃仅作用于本轮，不改变之后的轮次。
- 倒计时到期会保存本段并打开结束面板，不擅自认定任务已完成。继续已到期的倒计时任务时转为累计正计时。
- 未完成任务、各段记录及活动计时均包含在 JSON 导出中；刷新后可继续。

默认主题和励志句子完全离线；只有用户主动填写图片网址时才会请求该图片。

### 统计

- 手工录入的实际记录与计时记录使用同一统计口径，计划区不计入实际学习时长；父子学科同选不会重复累计。
- 日报、月历与统计使用实际秒数累计，短暂停段不再逐段补足一分钟；不足一分钟的时长可显示秒数。
- 累计专注次数、总时长和日均时长；
- 今日专注次数和时长；
- 按本日、本周、本月、本年或自定义日期范围查看学科时长分布，并可切换柱状图或扇形图；
- 本月每日专注折线图；
- 本年每月专注折线图；
- 支持一级、二级和三级学科筛选；
- 每块统计卡片可以单独隐藏或显示。

### 学科管理

- 独立的学科管理模块，可添加或删除一级学科。
- 每个学科可以设置颜色、文字大小、透明度、加粗、斜体和默认复习规则。
- 支持添加二级和三级科目，并可分别决定是否生成复习任务。
- 时间轴事件弹窗使用可筛选的单一学科路径输入框，选择后显示完整一级、二级、三级路径。
- 学科详情包括本月专注日历、当前/最高连续打卡、累计专注、年度热力图和历史记录。
- 学科历史记录可点击，直接打开对应事件详情。
- 本月专注日历和年度热力图日期标记均为 20×20；年度无记录日期为白色，有记录日期按时长使用学科颜色深浅。

### 页面与数据

- 顶栏采用紧凑设计，设置、导入导出和撤销重做收纳在右上角“•••”菜单。
- “清空全部事件”仅位于设置的二级页面，降低误触风险。
- 页面本身固定不滚动，时间轴和复习任务列表各自独立滚动。
- 数据保存在浏览器 `localStorage`，支持 JSON 导入导出、撤销和重做；数据格式版本为 10，兼容历史事件及复习数据。
- 设置面板提供“重载配置”，可重新读取系统设置和学科配置并重渲染关联组件，无需整页刷新。
- “分享学习日报”会打开纯白 PNG 预览，展示总时长、事件数、待复习数、学科占比环图和当天时间轴。核对后点击“保存 PNG”，也可右键或长按图片保存。
- 项目包含 Web App Manifest 与 Service Worker。通过本地 HTTP 服务或 HTTPS 打开后，可在 Edge 中安装为独立应用、固定到任务栏并离线打开。

### 平台能力边界

- 浏览器完全冻结或操作系统休眠时，普通网页、定时器和 Service Worker 都无法保证准点执行。本项目通过真实时间补查、活动计时持久化、系统通知和浏览器支持时的 Document Picture-in-Picture 悬浮小窗尽量降低影响；系统“勿扰”模式、通知权限和后台节流仍由 Windows/浏览器控制。
- 项目没有服务器和账号系统，因此不会把学习数据自动上传或跨设备同步。需要换设备时，请导出 JSON，再在另一设备导入。
- 随机网络图片与在线名言依赖第三方接口、跨域策略和网络状态；为保证纯前端离线可用，内置主题与名言保存在本地，同时允许用户填写图片网址或选择本地图片。

## 使用方法

直接用浏览器打开 `index.html` 即可使用主要功能，无需安装依赖。若要启用离线缓存、系统通知和“安装到桌面”，请在项目目录启动任意静态 HTTP 服务，例如：

```powershell
python -m http.server 4173
```

然后用 Edge 打开 `http://127.0.0.1:4173/`。

1. 点击“在时间轴选时间”，或按 `Ctrl + Enter`。
2. 在计划区或记录区点击开始时间，再点击结束时间。
3. 选择一级、二级或三级学科，补充学习动作、事件名称、资料位置、掌握程度和摘要后保存。
4. 点击右侧学科开始计时；暂停保存当前时段，再从未完成列表继续，最终完成后才生成复习安排。
5. 在复习卡片上点击“开始复习”，完成后保存，复习状态和时间轴会同步更新。
6. 通过“待清池”集中处理遗留问题；章节未完部分可填写在任务的遗留内容中。
7. 点击日期查看月历，点击“统计”或“学科管理”进入对应模块；右上角菜单可分享日报或备份数据。

按 `Esc` 可以退出选点、关闭弹窗或退出沉浸界面；`Ctrl + Z` 和 `Ctrl + Y` 分别用于撤销和重做。

## 项目文件

```text
index.html   页面结构与各功能模块
styles.css  页面样式、响应式布局、图表和沉浸主题
app.js      时间轴、复习、统计、学科、计时和数据逻辑
manifest.webmanifest  可安装 Web App 配置
sw.js        离线缓存 Service Worker
icon.svg     应用图标
```

清理浏览器数据前，建议先通过右上角菜单导出 JSON 备份。
