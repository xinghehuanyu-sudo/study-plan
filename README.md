# 学习日志时间轴

一个无需构建、无需联网的纯前端学习计划工具。页面以双栏时间轴展示每日的计划与实际记录，并提供复习任务、专注计时和本地数据备份。

## 功能

- **直接选点添加**：点击“在时间轴选时间”，先点开始、再点结束；默认在计划区选点，也可切换到记录区。
- **简洁时间轴**：中央小时轴使用 `1、2、3…` 格式；常态不显示横向分钟文字或密集刻度，选点时仅显示当前小时的辅助点。
- **紧凑事件显示**：事件只显示一条时间范围与内容，支持双击编辑、右键编辑或删除。
- **纯白图片导出**：导出的 PNG 使用纯白背景，不包含选点、悬停等交互标记。
- **专注计时**：学科可在设置中维护；支持正计时和倒计时，结束后填写详情并自动写入记录区。
- **复习任务**：学习记录可生成复习计划，并按今天、本周、本月或全部筛选。
- **数据管理**：使用 `localStorage` 自动保存，支持 JSON 导入/导出、撤销、重做与清空。
- **可调设置**：起始小时、小时高度、双栏占比、选点间隔、隐藏时段、学科颜色与透明度。

## 使用

直接用浏览器打开 `index.html` 即可。

1. 点击“在时间轴选时间”。
2. 在计划区依次点击开始点和结束点。
3. 补充学科与内容，保存后事件会显示在时间轴上。
4. 在“专注计时”中点击学科即可开始，结束后填写详情，记录会自动加入时间轴右侧。

## 文件

```text
index.html   页面结构
styles.css  页面样式与响应式布局
app.js      时间轴、数据、导出和专注计时逻辑
```

数据默认保存在浏览器本地。清理浏览器数据前，建议先使用“导出数据”保存 JSON 备份。
